    CURSOR TEAM ADMIN API

    Cursor team usage

    Not connected

    Read the trailing 30 days of official team daily-usage and current-cycle spending aggregates. Requires a team Admin API key configured in the server environment.

    Data boundary
    • Daily team activity and most-used model, aggregated by day locally.
    • Current-cycle spend total only.
    • Member names, emails, IDs, roles, chat text, and credentials are discarded before the response reaches this page.

    OpenAI organization API aggregates require OPENAI_ADMIN_KEY in the server environment.

    SUPPORTED
    What AI Usage Lens can do
    • Analyze explicit, user-owned request records.
    • Show input, cached input, cache writes, output, and reasoning when supplied.

    • Read documented Codex session usage and Cursor team aggregates with explicit consent.
    NEVER CLAIMED
    What remains unavailable
    • Unseen transcript text or message metadata.
    • Per-message Cursor tokens from team aggregate endpoints.
    • Subscription tokens as billable API dollars.
    • Reset times or prices absent a source.
    Import contract
    Use token-lens/v1 per-request deltas and stable IDs. Optional detail fields remain explicitly unavailable when omitted. Duplicate conflicts and cumulative snapshots are rejected.
