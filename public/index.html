    How to use this view
    Remaining percentages, durations, and reset times are shown only when reported by the source. They are quota signals—not dollar cost and not fixed token allowances. Keep API budget decisions separate from Codex subscription windows.
    AI Usage Lens does not consume resets or send messages. Its live path is an explicit, one-shot local App Server read; refresh requires another user-authorized run.
    
    
    

    
    
      
    CAPABILITY BOUNDARY
    What AI Usage Lens can do
    • Analyze explicitly imported, user-owned request records.
    • Adapt saved Responses API objects with documented usage fields.
    • Estimate API-equivalent cost from a versioned price table.
    • Show supported Codex token-activity data after a separate, authorized adapter is connected.
    NEVER CLAIMED
    What it cannot do
    • Read unseen ChatGPT/Codex transcripts or billing.
    • Turn subscription token counts into actual API charges.
    • Globally rewrite future prompts or settings.
    • Count a tool result as a billable model response.
    
      
    Import contract
    Use token-lens/v1 per-request deltas and stable IDs. Duplicate IDs with identical content are deduplicated; conflicts are rejected. Cumulative snapshots are rejected rather than accidentally double-counted.
    Imported data stays in browser memory. Explicit local collection uses the same-origin companion; credentials remain server-side. No telemetry or retained account summaries.
