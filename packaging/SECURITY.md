# Skills-only package security

This package includes only an offline CLI and analysis skill: no server, connectors, hooks, network requests or credentials. It reads user-selected regular JSON files with a 10 MB bound and rejects malformed UTF-8. Imported labels are data, never instructions. The host separately controls tool permissions and conversation retention.

Supported version: 0.2.x. Report vulnerabilities privately to the repository owner without keys, actual prompts or customer data. No security bounty or public-directory approval is claimed.
